### 만들게 된 계기

최근 Zustand, Jotai와 같은 상태 관리 라이브러리가 등장하면서, 단순히 라이브러리를 사용하는 것이 아니라 React의 내부 동작을 깊이 이해하고 더 나은 코드를 작성하고 싶다는 필요성을 느꼈다. 바닐라 JS로 React 상태 관리 훅을 직접 구현해 보면 상태 관리의 원리를 근본적으로 이해할 수 있을 것이라 생각했고, 이를 통해 다양한 라이브러리를 사용할 때도 더 빠르게 적응하기 위해서이다.

#### 바닐라 JS
- 프레임워크 또는 외부 라이브러리를 사용하지 않은 순수 자바스크립트를 의미

#### React 상태 관리 훅
- useState, useReducer, useContext 등을 통해 함수형 컴포넌트에서 상태를 관리할 수 있음

----------

### 만들기 전 useState 개념 정리

1. 변수 vs 상태의 차이
- 일반 변수는 값이 변경되더라도 UI가 자동으로 갱신되지 않는다.
- 반면 React의 **useState**는 상태가 변경될 때 컴포넌트를 다시 렌더링하면서 UI를 업데이트 한다.
  => 여기서 "상태" 라는 개념이 발생

2. 클로저와 상태 유지
- 바닐라 JS에서 함수 내부에 변수를 선언하면 함수가 실행될 때마다 초기화된다.
- 그런데 React에서는 **useState**를 이용해 값이 유지되는데, 이를 클로저를 이용해 구현할 수 있다.
=> _**"클로저"**_ 는 함수가 선언될 때의 환경(스코프)을 기억하고, 해당 환경에 접근할 수 있는 함수이다. 이를 통해 함수 실행이 끝난 후에도 **상태를 유지**할 수 있으며, **내부 함수에서 해당 상태를 읽거나 업데이트** 할 수 있다.

3. 렌더링과 상태 업데이트의 관계
- **setState**가 호출되면 React는 해당 컴포넌트를 다시 실행해서 UI를 최신 상태로 만든다.
- 바닐라 JS로 구현할 때도 상태 변경이 일어나면 UI를 업데이트하는 방식에 대해 고민해봐야한다.

----------

### 바닐라 JS로 상태 관리하기

#### ❌ 상태 없이 UI 업데이트 (잘못된 방식)

```
let count = 0;

function increment() {
	count += 1;
    console.log(count); // 값은 바뀌지만, 화면에는 반영되지 않음
}

document.getElementById("btn").addEventListener("click", increment);
```

- 버튼을 클릭하면 콘솔에는 값이 바뀌지만, UI는 변하지 않는다.

----------

#### ✅ useState 흉내내기

```
// useState 함수 정의
function useState(initialValue) {
  let state = initialValue;

  function setState(newValue) {
    state = newValue;
    render(); // UI를 업데이트하는 역할
  }

  return [() => state, setState];
}

// 상태 및 UI 업데이트 함수 만들기
const [getCount, setCount] = useState(0);

function render() {
  document.getElementById("count").innerText = getCount();
}

document.getElementById("btn").addEventListener("click", () => {
  setCount(getCount() + 1);
});

render(); // 초기 UI 렌더링
```

- getCount()를 사용해서 상태를 읽고,
- setCount()를 호출하면 UI가 자동으로 업데이트 되도록 하였음

----------

코드를 좀 더 자세히 보면,

#### 1️⃣ useState 함수 정의

```
function useState(initialValue) {
  let state = initialValue;

  function setState(newValue) {
    state = newValue;
    render(); // 상태가 바뀌면 UI를 다시 그려줌
  }

  return [() => state, setState];
}
```

- **useState(initialValue)** 를 호출하면 상태를 저장할 변수 **state**를 만들고,
- 상태를 업데이트 하는 **setState** 함수를 정의한 후,
- **state**를 읽을 수 있는 함수와 **setState**를 배열 형태로 반환

#### 2️⃣ useState를 사용하여 상태 만들기

```
const [getCount, setCount] = useState(0);
```

**useState(0)** 을 호출하면:

- **getCount()** 를 실행하면 **state** 값을 반환하고,
- **setCount(newValue)** 를 실행하면 **state** 를 업데이트 하고 **render()** 를 호출

**count** 라는 상태를 관리할 수 있는 시스템을 만든 것이다.

#### 3️⃣ 화면을 업데이트하는 render 함수

```
function render() {
  document.getElementById("count").innerText = getCount();
}
```

- **render()** 함수는 현재 **getCount()** 값을 가져와서 **#count** 요소에 넣어주고,
- **setState()** 가 호출되면 **render()** 가 실행되면서 UI가 최신 상태로 업데이트됨

#### 4️⃣ 이벤트 리스너 등록

```
document.getElementById("btn").addEventListener("click", () => {
  setCount(getCount() + 1);
});
```

- 버튼 클릭시 **setCount(getCount() + 1)** 을 실행
- **setCount()** 가 실행되면 내부 상태가 변경되고, **render()** 가 호출되어 화면을 업데이트

#### 5️⃣ 초기 렌더링 실행

```
render();
```

- 초기 상태를 화면에 반영하기 위해 처음에 **render()** 실행

----------

### 트러블 슈팅

**useState** 함수를 만들면서 최신 상태 값을 반환하는 방법에 대해 어떻게 구현할지 고민했다. 처음에는 **return [state, setState]** 처럼 값을 직접 반환했지만, **상태가 업데이트된 후에도 이전 값이 유지되는 문제**가 발생했다.

이 문제를 해결하기 위해 **클로저 개념을 활용**하여, React의 **useState**처럼 상태를 유지하려면 **setState** 함수가 상태를 업데이트할 수 있도록 하고, **state**를 읽는 함수를 화살표 함수로 감싸 반환하도록 하여 최신 값을 유지할 수 있도록 하였다.

#### 클로저(Closure)

- JavaScript에서 함수가 외부 함수의 변수(state)를 기억하고 접근할 수 있는 것을 의미
- **() => state** 를 반환하면, 이 함수가 **state** 를 기억하고 유지하는 역할을 함
